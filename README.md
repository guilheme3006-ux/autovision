# AutoVision

Projeto acadêmico de desenvolvimento web sobre o universo automotivo.

## Sobre o projeto

O AutoVision é um site informativo que apresenta veículos esportivos,
modelos de luxo e supercarros. O projeto foi desenvolvido utilizando
HTML5, CSS3 e JavaScript.

## Páginas do site

- Início: apresentação do projeto.
- Modelos: catálogo com seis veículos e pesquisa dinâmica de modelos.
- Notícias: informações e novidades do mundo automotivo.
- Comparativo: tabela para comparar veículos.
- Contato: formulário de contato com validação.

## Funcionalidades

- Navegação entre cinco páginas.
- Layout responsivo para celular, tablet e computador.
- Catálogo de veículos organizado em cartões.
- Comparação de veículos.
- Pesquisa de modelos por fabricante utilizando a API vPIC da NHTSA.
- Validação de campos do formulário de contato.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- API vPIC da NHTSA

## Como executar

1. Abra a pasta AutoVision no Visual Studio Code.
2. Abra o arquivo index.html.
3. Execute pelo navegador, preferencialmente utilizando a extensão Live Server.

## API utilizada

A consulta de fabricantes e modelos utiliza a API pública vPIC,
disponibilizada pela NHTSA.

Endereço: https://vpic.nhtsa.dot.gov/api/

A disponibilidade de modelos depende dos dados cadastrados na API.

## Observação

O formulário de contato possui validação e confirmação visual no navegador.
Ele ainda não realiza envio real de mensagens para um servidor ou e-mail.
